# Features Overview

This document explains the feature and label definitions generated by the feature pipeline in this package.

## Data Sources and Tables

The feature pipeline reads price data and macro data, and produces a daily feature table:

- Prices table: `raw_prices`
- Macro table: `macro_features`
- Output table: `features_daily`

Labels are generated separately into:

- Labels table: `labels_regime`

## Feature Construction (build.py)

The feature builder aligns all time series to a common business-day calendar and then computes per-ticker features. All features are computed per ticker and joined with macro features on date.

### Calendar Alignment

- The master index is a business-day calendar between the max common start and min common end of price and macro data.
- Missing dates in price data are forward-filled to align with the calendar.

### Returns

- `logret`: log return of the close price at time t.
  - Definition: `log(close_t) - log(close_{t-1})`

- `logret_lag{L}`: lagged log returns for each lag L in the configuration (default: 1, 5, 20).
  - Definition: `logret` shifted by L days.

These features represent short-term and medium-term price dynamics.

### Realized Volatility Proxies

- `rv_{W}`: realized volatility proxy computed as rolling standard deviation of `logret` over window size W (default: 5 and 20).
  - Definition: rolling std of `logret` over the last W business days.

These are observable volatility measures at time t. They are not forward-looking, but they can be highly correlated with the future volatility label.

### Macro Features

The pipeline loads macro time series, applies a transformation, and then builds lags.

- Base macro columns: `vix`, `fed_assets`, `tga`, `rrp`, `m2`, `ffr`, `sofr`, `net_liquidity` (only those present).
- Transformations (configured by `macro_transform`):
  - `diff`: first difference
  - `pct_change`: percent change
  - `logdiff`: log difference

For each transformed macro series, lagged versions are created:

- `{macro}_{transform}_lag{L}` for each lag L (default: 1, 5, 20).

These features represent short- and medium-term macro changes.

## Label Construction (labels.py)

Labels are derived from forward-looking volatility computed from returns.

### Forward Volatility Label

- `vol_fwd`: forward volatility for horizon h (default: h = 5 and 20).
  - Definition: rolling standard deviation of future log returns over the window `[t+1, t+h]`.
  - This is a forward-looking quantity and is not observable at time t.

### Regime Label

The `regime` label is computed later during dataset construction. It is not stored in the labels table.

- `regime`: discretized class label based on quantiles of `vol_fwd` in the training split.
  - Example (3 bins): 0 = low volatility, 1 = medium, 2 = high.

## Modeling Notes

- The final classifiers predict `regime`, not `vol_fwd` directly.
- `vol_fwd` is the underlying target that defines the regimes.
- `rv_{W}` features are observable at time t and can be used as inputs, but they may be correlated with `vol_fwd`.
- If SARIMAX is used, it should be trained on an observable target (such as `rv_20`) to avoid future leakage.
